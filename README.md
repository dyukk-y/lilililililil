# Telegram-бот приёма и автоматической публикации постов

Telegram-бот на aiogram 3 для приёма постов от пользователей с частично
автоматизированной модерацией (стоп-слова, дедупликация, ключевые фразы),
публикацией по расписанию, платными Stars-функциями (поиск автора,
ускорение проверки), удалением по заявкам и подробной админ-панелью с
динамическими настройками — плюс рассылки, чёрный список и баны.

## Как это работает

1. Пользователь присылает пост (текст/с фото, минимум 3 слова).
2. Бот проверяет: стоп-слова (маты/оскорбления/спам), повтор текста
   (нечёткое сравнение) и осмысленность текста (эвристика против
   мешанины по клавиатуре — не путать со сленгом, он разрешён). Если
   что-то не так — пост отклоняется мгновенно. Для админов проверка на
   осмысленность текста не применяется.
3. Сразу после отправки пользователь получает **одно** сообщение: "пост
   отправлен на модерацию, в очереди N постов" — бот **не сообщает**,
   будет ли пост опубликован автоматически или уйдёт на ручную проверку,
   и не называет время публикации. Под сообщением — кнопка платного
   ускорения проверки (Telegram Stars).
4. Дальше пост уходит по одному из двух путей:
   - **Автопубликация**: текст без фото, содержащий одну из ключевых фраз
     ("что за", "расскажите про", "понравилась" и т.п. — список
     редактируется в админ-панели) — получает случайное время публикации
     в пределах дневного окна (по умолчанию 8:00–23:59, Новосибирск) с
     учётом дневного лимита (по умолчанию 10 постов/день).
   - **Ручная модерация**: фото (нагота отклоняется автоматически через
     NudeNet, остальное — только вручную, возраст на фото автоматика не
     оценивает) или текст без ключевых фраз. Даётся 24 часа (настраивается)
     на решение модератора, иначе пост отклоняется автоматически.
5. Модераторы/администраторы получают карточку каждого поста с полными
   деталями (в отличие от пользователя) и в любой момент могут
   опубликовать его немедленно или отклонить вручную.
6. Если за день опубликовано меньше дневного лимита (например, из-за
   удаления поста или нехватки постов с ключевыми фразами) — фоновая
   ребалансировка автоматически подтягивает на сегодня посты, изначально
   запланированные на будущие дни.
7. Опубликованный пост можно попросить удалить (кнопка в FAQ) — если
   запрос от автора или упомянутого в посте человека, удаляется сразу;
   иначе решение принимают назначенные рецензенты (или запрос отклоняется
   автоматически через 24 часа без ответа). При удалении освободившийся
   слот дневной квоты тут же подтягивается ребалансировкой.
8. Через FAQ можно (платно, за Telegram Stars) узнать автора любого поста
   в канале по ссылке.
9. Два супер-администратора могут менять почти любые настройки бота
   (цены, лимиты, ID чатов, пороги автомодерации) прямо в админ-панели,
   без перезапуска, и выгружать список пользователей в Excel.

## Структура проекта

```
app/
  config.py         # чтение переменных окружения (стартовые значения), без секретов в коде
  runtime_settings.py  # динамические настройки (цены, лимиты, ID чатов) —
                     #   редактируются в админ-панели без перезапуска
  loader.py         # создание Bot/Dispatcher, настройка логирования
  database.py       # вся работа с SQLite (без обращений к Bot API),
                     #   включая дедупликацию, очередь публикации, статистику,
                     #   ключевые фразы автопубликации, покупки за Stars
  services.py       # функции, которым нужен Bot API: проверка подписки,
                     #   публикация/отклонение поста, маршрутизация постов,
                     #   заявки на удаление, поиск автора, приоритетный буст
  scheduler.py      # подбор времени публикации, ребалансировка дневной
                     #   квоты, фоновые циклы автопубликации и бэкапа БД
  moderation_photo.py  # NSFW-проверка фото (NudeNet), бесплатно и локально
  text_quality.py   # эвристическая проверка текста на "бред" (без словаря)
  keyboards.py      # inline-клавиатуры
  states.py         # FSM-состояния
  validators.py      # проверки чата/темы и валидация ввода (в т.ч. мин. 3 слова)
  middlewares.py     # проверка чата/темы, подписки, бана, отлов ошибок
  handlers/
    start.py            # /start
    subscriptions.py    # управление обязательными подписками (админ, в т.ч. закрытые)
    posting.py          # приём поста, автопроверки, единое уведомление о приёме
    moderation.py       # ручная публикация/отклонение поста модератором
    misc.py              # правила, меню, профиль (с полной статистикой), FAQ, реклама
    bans.py               # /ban, /unban, список забаненных
    admin_panel.py        # админ-панель
    pub_blacklist.py      # стоп-слова (маты/оскорбления/спам) для публикаций
    auto_approve_phrases.py  # ключевые фразы для автопубликации (админ)
    admin_stats.py         # статистика, логи, ручной бэкап БД
    admin_posts.py          # очередь публикаций, форс-паблиш/отклонение админом
    settings_admin.py       # динамические настройки + экспорт пользователей (супер-админы)
    broadcast.py             # рассылки
    comments.py               # учёт комментариев пользователей в канале (для профиля)
    post_deletion.py          # заявки на удаление опубликованного поста
    author_lookup.py          # платный поиск автора поста (Telegram Stars)
    priority_boost.py         # платное ускорение проверки поста (Telegram Stars)
    payments.py                # единая точка обработки Stars-платежей
main.py              # точка входа: роутеры, middleware, планировщик, polling
```

## Установка и запуск

### Требования
- Python 3.10+

### Шаги
```bash
git clone <ваш форк>
cd <папка проекта>

python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env
# заполните .env реальными значениями (см. ниже)

python main.py
```

### Переменные окружения

⚠️ Все переменные, кроме `BOT_TOKEN`, `DB_NAME`, `PUBLISH_TIMEZONE`,
`BACKUP_DIR`, `DELETION_REVIEWERS` и `SUPER_ADMINS`, используются только
как **стартовые** значения — после первого запуска их можно менять прямо
в админ-панели ("⚙️ Настройки бота", только для `SUPER_ADMINS`) без
перезапуска бота; правки `.env` для уже сохранённых ключей больше не
действуют.

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `MAIN_CHANNEL_ID` | да | ID канала для публикации одобренных постов |
| `ADMINS` | да | ID администраторов через запятую |
| `COMMENTS_CHAT_ID` | нет | ID чата комментариев (для счётчика комментариев в профиле) |
| `MODERATORS_CHAT_ID` / `MODERATORS_TOPIC_ID` | нет | Чат и тема модераторов (ручной форс-паблиш/отклонение) |
| `ADMINS_CHAT_ID` / `ADMINS_TOPIC_ID` | нет | Чат и тема администраторов (информационные уведомления) |
| `DB_NAME` | нет | Имя файла БД (по умолчанию `smotrbot.db`) — не редактируется в панели |
| `PUBLISH_TIMEZONE` | нет | Часовой пояс окна публикации (по умолчанию `Asia/Novosibirsk`) — не редактируется в панели |
| `PUBLISH_WINDOW_START_HOUR` / `PUBLISH_WINDOW_END_HOUR` / `PUBLISH_WINDOW_END_MINUTE` | нет | Окно публикации в течение дня (по умолчанию 8:00–23:59) |
| `DAILY_PUBLISH_LIMIT` | нет | Сколько постов публикуется за день (по умолчанию 10) |
| `MIN_SLOT_GAP_MINUTES` | нет | Минимальный зазор между временем публикации постов (по умолчанию 20 мин) |
| `DUPLICATE_REPEAT_LIMIT` | нет | После скольких похожих повторов пост автоотклоняется (по умолчанию 5) |
| `DUPLICATE_SIMILARITY_THRESHOLD` | нет | Порог "похожести" текста, 0..1 (по умолчанию 0.87) |
| `NSFW_EXPLICIT_THRESHOLD` | нет | Порог уверенности NudeNet для автоотказа фото, 0..1 (по умолчанию 0.65) |
| `DELETION_REVIEWERS` | нет | ID через запятую — кто решает по заявкам на удаление постов — не редактируется в панели |
| `DELETION_REQUEST_TIMEOUT_HOURS` | нет | Через сколько часов заявка на удаление отклоняется автоматически (по умолчанию 24) |
| `MODERATION_TIMEOUT_HOURS` | нет | Через сколько часов пост на ручной модерации отклоняется автоматически (по умолчанию 24) |
| `AUTHOR_LOOKUP_PRICE_STARS` | нет | Цена расшифровки автора поста в Telegram Stars (по умолчанию 100) |
| `PRIORITY_BOOST_PRICE_STARS` | нет | Цена ускорения проверки поста в Telegram Stars (по умолчанию 50) |
| `SUPER_ADMINS` | нет | ID через запятую — кто может менять настройки и выгружать Excel — не редактируется в панели |
| `BACKUP_DIR` / `BACKUP_INTERVAL_MINUTES` / `BACKUP_KEEP_LAST` | нет | Папка (не редактируется в панели), периодичность и глубина хранения бэкапов БД |

Как узнать ID чата/темы: напишите [@userinfobot](https://t.me/userinfobot),
либо добавьте бота в чат и посмотрите ID через `getUpdates`/логи бота.

**Важно:** файл `.env` и файл базы данных (`*.db`) не должны попадать в git —
оба уже добавлены в `.gitignore`. Если раньше `.env` или `.db` были
закоммичены, обязательно перевыпустите токен бота и удалите файлы из истории
git (например, через `git filter-repo`), а не только из рабочей копии.

## Функционал

- 📝 Приём поста от пользователя (текст, с фото или без), минимум 3 слова
- 🔍 Обязательные эмодзи-маркеры, ограничение длины
- 🤖 **Автомодерация**: стоп-слова (маты/оскорбления/спам — стартовый список уже
  встроен), нечёткая дедупликация текста (опечатки/пробелы не спасают) и
  проверка на бессмысленный текст (для обычных пользователей; админам можно
  всё) — явный брак отклоняется мгновенно, без участия человека
- 🔑 **Ключевые фразы для автопубликации**: текст без фото публикуется
  полностью автоматически, только если содержит одну из настраиваемых
  ключевых фраз ("что за", "расскажите про", "понравилась" и т.п.) —
  иначе, как и любое фото, уходит на ручную модерацию
- 📷 **NSFW-фильтр фото** (NudeNet, бесплатно и локально): откровенная нагота
  отклоняется автоматически; любое другое фото уходит на обязательную
  ручную модерацию — возраст на фото автоматика не оценивает
- ⏳ **Единый срок модерации**: любой пост на ручной проверке автоматически
  отклоняется, если решение не принято в течение 24 часов (настраивается)
- 📅 **Автопубликация по расписанию**: одобренные текстовые посты публикуются
  в течение дня в случайное время (по умолчанию 8:00–23:59, Новосибирск),
  не более `DAILY_PUBLISH_LIMIT` постов в сутки — пользователю точное время
  никогда не раскрывается, только размер очереди
- ⚖️ **Ребалансировка дневной квоты**: если сегодня опубликовано меньше
  лимита (удаление поста, нехватка постов с ключевыми фразами) — бот сам
  подтягивает на сегодня посты, запланированные на будущие дни
- 👮 Ручной контроль в любой момент: модераторы могут опубликовать пост
  немедленно или отклонить его; администраторы управляют очередью через
  админ-панель
- 🗑 **Заявки на удаление поста**: автор/упомянутый в посте — удаление сразу,
  иначе решение принимают назначенные рецензенты (24 часа на ответ, потом
  автоотклонение)
- 🔎 **Платный поиск автора поста** за Telegram Stars — через FAQ
- ⚡ **Платное ускорение проверки поста** за Telegram Stars — администраторы
  получают пометку "приоритетная публикация"
- ⚙️ **Динамические настройки**: два супер-администратора могут менять
  почти любой параметр бота (цены, лимиты, ID чатов, пороги автомодерации)
  прямо в админ-панели, без правки `.env` и без перезапуска
- 📥 **Экспорт пользователей в Excel** (только для супер-админов): ID,
  юзернейм, дней в боте, постов написано, потрачено звёзд — по убыванию трат
- 🛡️ Защита от гонки: атомарные переходы статусов (публикация/отклонение
  поста, решение по заявке на удаление) — при одновременных действиях
  срабатывает только одно (см. `try_finalize_post`, `claim_deletion_request`)
- 💾 **Надёжность**: WAL-режим SQLite, автоматическое восстановление
  "подвисших" постов после падения бота (с различением сбоя и намеренного
  ожидания модератора), периодические и ручные резервные копии БД
- 👤 Расширенный профиль: статистика по постам (отправлено/опубликовано/
  отклонено/в очереди), комментарии и упоминания в канале
- 📊 Админ-панель: статистика, очередь публикаций, логи действий, бэкап БД
- 🚫 Баны пользователей, стоп-слова для публикаций
- 📢 Рассылки (текстом и с фото) всем зарегистрированным пользователям
- 🔔 Обязательная подписка на каналы/группы (в том числе закрытые/приватные)
  перед использованием бота
